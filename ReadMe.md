## What is miniFoam?
A computational mechanics playground, mostly on top of OpenFOAM.

## Install
```bash
## In your terminal:
./Allwmake.sh
```

### Dependencies
- `foam-extend-4.0`, installable from [here](https://openfoamwiki.net/index.php/Installation/Linux/foam-extend-4.0).
