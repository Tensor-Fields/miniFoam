# Run
Edit *test_table__READ_ONLY.dat* and *run.slurm*, then
```bash
sbatch run.slurm # If running using slurm
# OR
study.sh # If running directly on the machine
```
When the run is done,
edit *plot.list*, and run
```bash
./study.gplt.sh
```

# Description
*test_table.dat* will be created
automatically when running starts.

To create a new study, go to .. (the parent dir), 
copy everything except the run-time generated files
into a new dir.
